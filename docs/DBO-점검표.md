# DBO 자가 점검표

산출 결과를 그대로 믿지 않고 **직접 확인하기 위한 목록** 입니다.

정년이 규칙대로 나오는지 한 사람씩 넣어 보며 확인했던 것과 같은 방식으로,
확정급여채무(DBO)를 만드는 요소를 하나씩 켜고 끄며 값이 예상대로 움직이는지
봅니다. 요소가 여러 개 겹치면 어디가 틀렸는지 알 수 없으므로, **한 번에 하나만**
바꾸는 것이 이 점검표의 원칙입니다.

확인은 [사번 조회] 화면에서 합니다. 그 화면은 전체 산출과 **같은 코드로** 그
사람만 다시 계산하므로, 거기 보이는 값은 전체 합계에 들어간 값 그대로입니다.

> 이 문서의 기대값은 **천원 단위로 반올림해** 적었습니다. 원 단위 끝자리는
> 근속을 날수로 세는 과정에서 몇 원씩 달라지므로, 천원 단위까지 맞으면 맞는
> 것으로 보십시오.

---

## 0. 점검용 자료 만들기

### 명부 — 한 사람만

| 칸 | 값 |
| --- | --- |
| 사번 | A0001 |
| 성별 | 남 |
| 생년월일 | 1980-12-31 |
| 입사일자 | 2015-12-31 |
| 30일 평균임금 | 5,000,000 |
| 직군 | 정규직 |
| 퇴직급여 제도구분 | DB |

나머지 칸은 모두 비웁니다. 개인 예외(정년연령·임금피크·잔여계약기간)가 하나라도
차 있으면 직군 규칙이 아니라 그 칸이 정년을 정하므로, 점검이 어긋납니다.

### 기초자료

| 칸 | 값 |
| --- | --- |
| 산출기준일 | 2025-12-31 |
| 직군 규칙 — 정년연령 | 60 |
| 직군 규칙 — 정년초과 가산연수 | 2 |

### 기초율 — 전부 끈 상태에서 시작

| 가정 | 값 |
| --- | --- |
| 할인율 | 5% (단일) |
| Base-up | 0% |
| 승급률 | 0% |
| 중도퇴직률 | 0% |
| 사망률 | 0% |
| 지급률 | 법정 (근속 × 1배) |

이 상태에서는 **정년퇴직 하나만** 남습니다. 탈퇴가 하나뿐이면 손으로 끝까지
계산할 수 있어, 엔진과 계산기를 맞대어 볼 수 있습니다.

## 1. 뼈대 세 개 — 여기가 틀리면 그 뒤는 볼 것도 없다

DBO 는 결국 이 셋의 곱입니다. 먼저 이것부터 봅니다.

- [ ] **근속 10.0055년** — 2015-12-31 부터 2025-12-31 까지.
  10.00 이 아니라 10.0055 인 것이 맞습니다. 윤년이 섞여 있어 일수로 세면
  10년보다 이틀쯤 깁니다. 여기가 딱 10.0000 으로 나오면 **연 단위로 끊고
  있다는 뜻** 이라, 중간정산·휴직이 있는 사람에서 어긋나기 시작합니다.
- [ ] **투영연수 15년** — 정년 60세 − 현재 45세.
- [ ] **퇴직급여추계액 약 50,027,000원** — 5,000,000 × 10.0055 × 1배.
  기준일에 당장 그만두면 받을 금액이며, 회사가 장부에 잡아 둔 추계액과
  맞대어 보는 자리입니다.

셋 중 하나라도 다르면 아래는 볼 필요가 없습니다. 먼저 명부의 날짜와 직군
규칙을 확인하십시오.

## 2. DBO 본체 — 손으로 끝까지 계산해 보기

```
DBO = 임금 × 총근속 × 지급률 × (과거근속 ÷ 총근속) ÷ (1 + 할인율)^투영연수
    = 5,000,000 × 25.0055 × 1 × (10.0055 ÷ 25.0055) ÷ 1.05^15
    = 50,027천원 ÷ 2.078928
    = 24,064천원
```

- [ ] **DBO 약 24,064,000원**
- [ ] **당기근무원가 약 2,405,000원** — DBO ÷ 과거근속. 지급률이 근속에 비례하고
  가정이 평탄하면 이 관계가 정확히 성립합니다. 성립하지 않으면 귀속(할당)이
  근속에 비례하지 않는다는 뜻이니, 지급률 규정에 누진·상한이 걸려 있는지
  보십시오.
- [ ] **듀레이션 15.00년** — 탈퇴가 정년 하나뿐이므로 지급 시점도 하나입니다.
- [ ] **DBO(정년) = DBO, DBO(중도) = 0, DBO(사망) = 0** — 퇴직률을 껐으므로
  전액이 정년 몫이어야 합니다.

## 3. 요소를 하나씩 켜 본다

위 상태에서 **한 칸만** 바꾸고 다시 산출합니다. 괄호 안은 이 조건에서 나와야
하는 값입니다.

### 3-1. 할인율 5% → 3%

- [ ] DBO **약 32,111,000원** (기준의 1.3344배)
- [ ] 손으로: 24,064천원 × (1.05 ÷ 1.03)^15 = 24,064천원 × 1.3344
- [ ] 할인율을 **내리면 채무가 늘어납니다.** 반대로 움직이면 부호가 뒤집힌
  것이니 즉시 멈추십시오.

### 3-2. Base-up 0% → 3%

- [ ] DBO **약 37,491,000원** (기준의 1.5580배)
- [ ] 손으로: 1.03^15 = 1.5580. 임금이 15년 동안 3%씩 오르므로 정확히 그만큼
  커집니다.
- [ ] 추계액은 **그대로 50,027,000원** 이어야 합니다. 추계액은 지금 그만둘 때
  받는 금액이라 미래 임금상승과 무관합니다. 추계액이 같이 커지면 임금상승을
  과거에까지 소급 적용하고 있다는 뜻입니다.

### 3-3. 임금 5,000,000 → 10,000,000

- [ ] DBO **약 48,128,000원** — 정확히 2배.
- [ ] 임금은 어느 항에도 곱해지므로 정확히 비례해야 합니다. 2배가 아니면
  반올림 단위나 상·하한이 걸려 있는지 보십시오.

### 3-4. 중도퇴직률 0% → 5%

- [ ] DBO **약 31,068,000원** — **늘어납니다.**
- [ ] 듀레이션 15.00 → **9.04년**
- [ ] 여기서 착각하기 쉽습니다. "일찍 나가는 사람이 생기면 채무가 줄어야
  하지 않나" 싶지만, 법정 지급률처럼 사유별 배수가 같으면 **받는 금액은 같고
  받는 시점만 앞당겨질 뿐** 이라 할인을 덜 받아 현재가치가 커집니다.
- [ ] 채무가 줄어드는 경우는 **중도퇴직 지급률이 정년보다 낮을 때** 입니다.
  회사 규정이 그렇다면 지급률 표에서 사유별로 나눠 넣고 다시 보십시오.

### 3-5. 사망률 0% → 1%

- [ ] DBO **약 25,706,000원**, 듀레이션 **13.33년** — 중도퇴직과 같은 이치입니다.
- [ ] 사망률은 성별로 갈립니다. 명부의 성별을 여자로 바꾸면 값이 달라져야
  합니다. 안 달라지면 성별이 안 읽히고 있다는 뜻입니다(주민번호 뒷자리 또는
  성별 칸을 확인하십시오).
- [ ] 사망률은 0.00003 처럼 아주 작은 값이라 표에서 눈으로는 0 처럼 보입니다.
  실제로 반영되는지는 값을 100배로 키워 보면 확실히 갈립니다.

### 3-6. 근속 0년 (신입)

생년월일 2000-12-31, 입사일자 2025-12-31 로 바꿉니다.

- [ ] DBO **0원** — 쌓인 근속이 없으므로 채무도 없습니다.
- [ ] 당기근무원가는 **0이 아닙니다** (약 906,000원). 올해 일한 몫은 원가로
  잡힙니다. 여기가 0이면 신입 인건비가 통째로 빠집니다.

### 3-7. 정년을 넘긴 사람

생년월일 1962-12-31 (63세), 입사일자 1997-12-31 로 바꿉니다.

- [ ] 정년 **65세** — 60세를 이미 넘겼으므로 현재 연령 63 + 가산연수 2.
- [ ] 투영연수 **2년**
- [ ] DBO **약 127,071,000원** = 5,000,000 × 28.0192 ÷ 1.05²
- [ ] 가산연수를 1로 바꾸면 정년 64세, 투영 1년이 되어야 합니다.
- [ ] 정년연령 칸을 **비우면** 정년이 없다는 뜻이므로, 나이가 몇이든
  현재 연령 + 가산연수가 됩니다.

## 4. 표로는 안 잡히는 것 — 자료를 넣어 확인할 목록

여기부터는 값을 손으로 예측하기 어려우므로, **방향과 관계** 를 봅니다.

### 사람이 제대로 세어졌는가

- [ ] 산출 인원 = 명부 재직자 수 − 제외자 수
- [ ] 제외 사유가 화면에 뜨는가 (DC 가입자 / 최소 근속 미달 / 임금 0 / 날짜
      누락). 아무 말 없이 사라지는 사람이 있으면 안 됩니다.
- [ ] DC 가입자를 DB 로 바꿔 보면 인원과 채무가 그만큼 늘어나는가
- [ ] 같은 사번이 두 줄인 사람(지급구간 분할)이 한 사람으로 세어지는가

### 근속이 제대로 세어졌는가

- [ ] **중간정산일** 을 넣으면 근속이 그 날부터 다시 세어지는가
- [ ] **휴직차감일수** 30일을 넣으면 근속이 약 0.082년(30÷365.25) 줄어드는가
- [ ] **가산근속연수** 3년을 넣으면 — 지급률을 찾는 근속만 3년 늘고, 귀속에
      쓰는 실제 근속은 그대로여야 합니다. 추계액은 늘고 근속 표시는 그대로면
      맞습니다.
- [ ] **차감근속연수** 도 같은 방식으로 반대 방향인가

### 정년이 제대로 잡혔는가 (이미 확인한 항목)

- [ ] 잔여계약기간 → 임금피크 → 개인별 정년연령 → 직군 규칙 순으로 세다
- [ ] 잔여계약기간 1년이면 투영 1년
- [ ] 임금피크 연령이 현재 연령보다 크면 그 연령에서 퇴직
- [ ] 개인별 정년연령 칸이 직군 규칙을 덮어쓰는가
- [ ] 정년 도달 시점을 '연말' 로 두면 투영연수가 정수로 떨어지고,
      '도달 즉시' 로 두면 생일에 따라 소수가 되는가

### 지급률(배수)이 제대로 걸렸는가

- [ ] 화면의 **지급률(누적 배수)** 이 규정 표의 그 근속 칸과 같은가
- [ ] 표에 없는 근속(예: 12.5년)이 **위아래 칸 사이 값** 으로 나오는가 (보간)
- [ ] 사유별로 다른 배수를 넣으면 DBO(정년)·DBO(중도)·DBO(사망) 이 그 비율로
      갈리는가
- [ ] **세 사유의 합이 총 DBO 와 정확히 같은가** — 한 칸을 잘못 넣어도 총액은
      조금만 움직이므로, 합계만 보면 못 잡습니다
- [ ] DB비율 0.5 를 넣으면 채무가 정확히 절반이 되는가
- [ ] 반올림 단위를 1,000원으로 두면 급여가 그 단위로 떨어지는가
- [ ] 최소 근속(가입자격) 1년을 걸면 근속 1년 미만인 사람이 빠지는가

### 할인율이 제대로 걸렸는가

- [ ] 신용등급을 바꾸면 할인율이 바뀌는가
- [ ] 만기별 금리(spot)를 쓸 때, 투영연수가 긴 사람일수록 더 긴 만기의
      금리가 적용되는가
- [ ] **듀레이션 × 할인율 변동 ≒ 채무 변동률** — 듀레이션 15년짜리 집단에서
      할인율을 1%p 올리면 채무가 대략 15% 줄어야 합니다. 민감도 표의 값과
      이 어림셈이 크게 어긋나면 둘 중 하나가 틀린 것입니다.

### 합계가 맞는가

- [ ] 총 DBO = 개인별 결과의 합 (결과 엑셀에서 열 합계)
- [ ] 총 근무원가 = 개인별 근무원가의 합
- [ ] 이자원가 ≒ 기초 DBO × 할인율 (회계기간이 1년일 때)
- [ ] 증감표의 기초 + 근무원가 + 이자원가 + 재측정 − 지급액 = 기말 DBO,
      잔차 0
- [ ] 직군별 채무의 합 = 총 채무
- [ ] 전기 자료를 연결했을 때 기초 DBO 가 전기 보고서의 기말과 같은가

### 회사 자료와 맞대어 보기

- [ ] 회사가 적어 온 **추계액** 과 우리 추계액의 차이가 몇 명에서, 얼마나
      나는가 (완전히 같을 수는 없지만, 몇 사람만 크게 튀면 그 사람의 임금·
      근속·지급률 중 하나가 다릅니다)
- [ ] **차년도 추계액** 까지 적어 왔다면, 우리 임금상승 가정이 회사 생각과
      같은 방향인가
- [ ] DBO ÷ 추계액 비율이 상식적인가 — 보통 70~90% 입니다. 100% 를 넘으면
      임금상승이 할인율보다 크게 잡혀 있다는 뜻이고, 50% 아래면 투영이 지나치게
      길거나 퇴직률이 과하게 걸려 있을 수 있습니다.

## 5. 한 장 요약

가장 자주 틀리는 순서대로 다섯 가지만 본다면:

1. **근속** — 중간정산일·휴직차감일수가 반영됐는가
2. **정년** — 개인 예외 칸이 직군 규칙을 조용히 덮어쓰고 있지 않은가
3. **지급률** — 화면의 누적 배수가 규정 표와 같은가
4. **사유별 합** — 정년 + 중도 + 사망 = 총 DBO
5. **듀레이션과 민감도** — 듀레이션 × 1%p ≒ 할인율 민감도

이 다섯이 맞으면 나머지는 대체로 따라옵니다.
