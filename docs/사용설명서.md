# 사용설명서

담당자용 안내입니다. 파이썬이나 프로그래밍 지식은 필요 없습니다.

---

## 1. 프로그램 받기

1. GitHub 저장소 → 위쪽 **Actions** 탭
2. 목록에서 `Windows 실행파일 빌드` 중 최근 것(초록 체크 표시) 클릭
3. 페이지 맨 아래 **Artifacts** → `연금계리산출-windows` 클릭해 내려받기
4. 압축을 풀면 두 파일이 나옵니다

| 파일 | 용도 |
|---|---|
| `연금계리산출.exe` | 더블클릭하면 창이 뜹니다. 보통 이것만 쓰면 됩니다 |
| `pension-cli.exe` | 명령프롬프트에서 배치로 돌릴 때 |

> 설치 과정이 없습니다. 원하는 폴더에 두고 바로 실행하십시오.
> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르십시오.
> 서명되지 않은 실행 파일이라 나오는 안내입니다.

---

## 2. 준비물 두 가지

### 명부 파일

기존에 쓰던 엑셀 통합문서 그대로입니다. 다음 세 시트가 있어야 합니다.

* `Input` — 산출기준일(C3), 평균임금 체크금액(C5), 직군 규칙(B12부터)
* `재직자명부` — 26행부터 데이터
* `퇴직자명부` — 22행부터 데이터

### 기초율 파일

**처음이라면 프로그램이 양식을 만들어 줍니다.**

1. `연금계리산출.exe` 실행
2. **명부 파일** 을 먼저 선택 (직군명을 가져오기 위해)
3. **[기초율 양식 새로 만들기]** 클릭 → 저장 위치 지정
4. 만들어진 엑셀을 열어 각 시트를 채운 뒤 저장

시트별로 채울 내용:

| 시트 | 무엇을 넣나 |
|---|---|
| `할인율` | 결산일 현재 우량회사채 수익률. 한 줄이면 전 기간 단일 |
| `임금상승률` | 승진·승급을 뺀 공통 인상률(Base-up). 연차별로 다르면 여러 줄 |
| `승급률` | 호봉·승진에 따른 인상률. 열 이름은 명부의 규정명과 같아야 합니다 |
| `퇴직률` | 연간 중도퇴직률. 과거 3~5년 경험률 권장 |
| `사망률` | 경험생명표 등의 `qx` |
| `지급률` | 월평균임금 대비 배수. **법정 퇴직금만 쓴다면 비워 두십시오** |
| `장기급여지급률` | 근속 포상 지급일수. 없으면 비워 두십시오 |

> **열 이름이 중요합니다.** `Input` 시트의 규정명 칸(G~N열)이나 명부의 규정 칼럼에
> 적은 이름과 기초율 시트의 열 머리글이 **글자 하나까지 같아야** 합니다.
> 다르면 해당 인원의 산출 결과에 "규정을 찾을 수 없음" 이 표시됩니다.

> **표는 계단식으로 읽습니다.** 퇴직률 시트에 20·35·50세 행만 있으면
> 27세인 사람은 20세 행 값을 씁니다. 모든 연령을 다 적을 필요는 없습니다.

## 3. 산출하기

1. `연금계리산출.exe` 실행
2. **1. 입력 파일** — 명부, 기초율, 결과 저장 위치를 지정
   (명부를 고르면 결과 경로는 자동으로 채워집니다)
3. **2. 산출 옵션** — 보통 그대로 두십시오
4. **3. 전기 산출 결과** — 작년 수치가 있으면 넣으십시오. 최초 평가면 비워 둡니다
   * 전기말 확정급여채무, 전기말 할인율
   * **전기 기초율 파일** 까지 넣으면 보험수리적손익이 경험조정과 가정변경으로
     나뉩니다. 주석 공시에 필요한 수치입니다
5. **[산출 실행]** 클릭
6. 아래 로그에 진행상황과 결과 요약이 나옵니다
7. **[결과 폴더 열기]** 로 엑셀을 여십시오

## 4. 오류가 났을 때

### "명부 검증에서 오류 N건이 발견되어 산출을 중단했습니다"

명부에 고쳐야 할 곳이 있습니다. 로그에 이렇게 나옵니다.

```
[ERROR] JAE_WAGE_BELOW_CHECK (재직자명부!K28) 사번=A003: 30일 평균임금 100원이 체크금액 1,000,000원 미만입니다
```

읽는 법: `재직자명부` 시트의 **K열 28행** 을 보라는 뜻입니다. 엑셀에서 그 칸으로
바로 가면 됩니다.

**오류를 모두 한 번에 보여 주므로**, 로그에 나온 곳을 전부 고친 뒤 한 번만 다시
돌리면 됩니다.

### 자주 나오는 오류

| 코드 | 뜻 | 조치 |
|---|---|---|
| `JAE_JOB_GROUP_UNKNOWN` | 명부의 직군이 `Input` 시트에 없음 | `Input` B열에 직군을 추가하거나 명부의 직군명을 맞추십시오 |
| `JAE_DUP_ID` | 사번 중복 | 메시지에 중복된 행 번호가 모두 나옵니다 |
| `JAE_BIRTH_DATE` | 생년월일을 해석 못 함 | `YYYY-MM-DD` 로 고치십시오 |
| `JAE_WAGE_BELOW_CHECK` | 평균임금이 체크금액 미만 | 임금을 확인하거나 `Input` C5의 체크금액을 조정 |
| `JAE_PLAN_MISSING` | 제도구분 공란 | `DB` / `DC` / `퇴직금제도` 중 하나 |
| `JAE_HIRE_AFTER_BASE` | 입사일이 산출기준일보다 늦음 | 기준일 이후 입사자는 명부에서 빼십시오 |
| `TOI_REASON_MISSING` | 퇴직사유 미입력 | 1~6 중 하나 (1:중도 2:사망 3:DC전환 4:정년 5:전출 6:사업처분) |
| `TOI_FUND_OVER_TOTAL` | 사외자산 지급액 > 총지급액 | 금액을 확인하십시오 |

### 검토용으로 일단 돌려보고 싶다면

**[검증 오류가 있어도 산출 강행]** 을 켜십시오. 다만 그 결과는 **검토용입니다.**
확정 공시 전에는 반드시 명부를 고치고 다시 돌리십시오.

### 경고(WARNING)는 무엇인가

산출은 되지만 담당자가 확인해야 하는 항목입니다. 자동으로 판단할 수 없어서
알려 드리는 것입니다.

* `JAE_NRA_NOT_FUTURE` — 정년을 이미 넘긴 사람. `Input` F열의 가산 연수를 확인
* `TOI_REASON_AMBIGUOUS` — 임금피크 중간정산의 분류가 종전 규칙와 시트 수식에서 갈림
* `XREF_ID_IN_BOTH` — 같은 사번이 재직·퇴직 양쪽에 있음 (DC 전환자면 정상)

## 5. 결과 엑셀 읽기

| 시트 | 쓸 곳 |
|---|---|
| `산출요약` | 재무제표 주석의 기본 수치. 인원·DBO·근무원가·이자원가·듀레이션 |
| `증감분석` | 주석의 확정급여채무 변동 내역 표 |
| `민감도분석` | 주석의 민감도 공시 |
| `개인별산출` | 검산용. 원가코드별 배분에도 씁니다 |
| `장기급여` | 기타장기종업원급여 (보험수리적손익을 당기손익으로 인식) |
| `검증리포트` | 명부 이슈 전체. 필터가 걸려 있습니다 |
| `UpLoad_Jae` / `UpLoad_Toi` | 기존 종전 규칙가 만들던 업로드 명부와 같은 형식 |

### 결과가 맞는지 빠르게 보는 법

**`산출요약` 의 확정급여채무 ÷ 퇴직급여추계액** 을 계산해 보십시오.
통상 **0.7 ~ 1.1** 입니다. 크게 벗어나면:

* 1보다 많이 크다 → 임금상승률이 할인율보다 지나치게 높지 않은지
* 0.7보다 작다 → 정년연령이 너무 멀지 않은지, 할인율이 과도하지 않은지

**민감도분석의 할인율 ±0.5%p 변동률** 은 대략 `듀레이션 × 0.5%` 여야 합니다.
듀레이션 9년이면 약 4.5%. 크게 다르면 기초율을 다시 보십시오.

## 6. 배치로 돌리기 (선택)

명령프롬프트에서:

```cmd
pension-cli calc 명부.xlsm 기초율.xlsx -o 산출결과.xlsx
pension-cli check 명부.xlsm -o 검증결과.csv
pension-cli template 기초율.xlsx --roster 명부.xlsm
pension-cli upload 명부.xlsm -o 업로드명부.xlsx
```

전기 수치를 넣으려면:

```cmd
pension-cli calc 명부.xlsm 기초율.xlsx -o 결과.xlsx ^
    --prior-dbo 8412530000 --prior-rate 4.8% --prior-assumptions 기초율_전기.xlsx
```

검증 오류가 있으면 종료 코드 `2` 로 끝나므로, 배치 스크립트에서 판정할 수 있습니다.

## 7. 자주 묻는 것

**Q. DC 가입자가 산출에서 빠졌습니다.**
정상입니다. 확정기여제도는 부담금을 납입하면 의무가 끝나므로 확정급여채무가
생기지 않습니다(K-IFRS 1019호 문단 51). `개인별산출` 시트의 `제외사유` 에
표시됩니다.

**Q. 장기급여채무가 0으로 나옵니다.**
`개인별산출` 옆 `장기급여` 시트의 `제외사유` 를 보십시오. 대개 둘 중 하나입니다.
① 명부의 `장기급여 산출대상여부` 가 `N`, ② 기초율의 `장기급여지급률` 시트에
해당 규정명 열이 없음.

**Q. 명부 열 위치를 바꿔도 되나요?**
안 됩니다. 열 배치가 고정되어 있습니다. 바꿔야 한다면 개발자에게
`readers.py` 의 열 표 수정을 요청하십시오.

**Q. 결과를 다시 재현할 수 있나요?**
같은 명부와 같은 기초율을 넣으면 항상 같은 값이 나옵니다. 난수를 쓰지 않습니다.
감사 대응을 위해 산출에 쓴 명부·기초율 파일을 결과와 함께 보관하십시오.
