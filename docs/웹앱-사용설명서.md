# 사용설명서

아이패드·휴대폰·PC 브라우저에서 쓰는 화면입니다. 설치할 것이 없고, 산출은
**기기 안에서** 돕니다.

---

## 처음 한 번

### 주소를 열면 됩니다

처음 열 때 30초쯤 걸립니다. 산출 엔진을 통째로 내려받아 기기에 넣는 시간이며,
**한 번만** 그렇습니다. 그 뒤로는 바로 뜨고 비행기 모드에서도 돕니다.

화면 위 띠에 `엔진을 준비하는 중…` 이 지나가고 `준비 완료` 로 바뀌면 쓸 수
있습니다.

### 받은 명부가 없어도 됩니다 — [자료실] 에 다 있습니다

앱을 처음 열면 이 안내가 한 번 뜹니다. **다시 보지 않기** 를 체크하고 닫으면
그 뒤로는 뜨지 않고, 내용은 여기(물음표)에 그대로 남습니다.

맨 오른쪽 **자료실** 탭에 이미 들어 있는 것들입니다.

| 무엇 | 언제 씁니다 |
|---|---|
| **명부 양식** | 회사에 그대로 보내는 서식. 작성요령·기본정보·퇴직급여규정·사외적립자산·재직자명부·퇴직자명부가 한 파일에 |
| **시험명부** | 같은 양식에 난수 자료를 채운 것. 실제 명부 없이 두드려 볼 때 |
| **기초율 빈양식 / 기본값** | 산출가정 워크북. 기본값에서 시작하면 빠릅니다 |
| **금리표** | 최근 결산일 곡선이 **이미 등록**되어 있습니다. 산출기준일과 다르면 화면이 알려 줍니다 |
| **표준률 원표** | 퇴직률·승급률·사망률. 사업장 규모별로 나뉘어 있습니다 |

올린 명부와 등록한 자료는 **이 기기 안에만** 남습니다. 어디로도 전송되지
않습니다.

### 홈 화면에 두면 앱처럼 열립니다

아이패드·아이폰 Safari 에서 **공유 → 홈 화면에 추가**. 주소창 없이 전체 화면으로
뜨고, 아이콘도 생깁니다.

> 홈 화면에 추가한 것과 Safari 로 연 것은 **저장소가 따로**입니다. 한쪽에서
> 저장한 산출이 다른 쪽에 안 보입니다. 하나로 정해 쓰시는 편이 낫습니다.

### 자료는 기기 안에만 있습니다

올린 명부도, 저장한 산출도 **서버로 가지 않습니다.** 그 브라우저 안에만
남습니다. 그래서 이런 성질이 있습니다.

- 인터넷이 끊겨도 산출됩니다
- 남이 볼 수 없습니다
- **Safari 방문기록·웹사이트 데이터를 지우면 함께 사라집니다**
- 기기를 바꾸면 따라오지 않습니다

마지막 두 가지 때문에 [자료실] 의 **보관함 내보내기** 가 있습니다. 결산이 끝날
때마다 한 번씩 내보내 두십시오.

## 화면 일곱 개

일하는 순서대로 놓았습니다.

| 탭 | 언제 |
|---|---|
| **산출** | 명부와 기초율을 걸고 실행합니다 |
| **산출가정 입력** | 기초율 파일 없이 화면에서 가정을 만듭니다 |
| **분석** | 결과를 그림과 표로 봅니다 |
| **계리평가 보고서** | 공시용 보고서를 만들어 PDF 로 저장합니다 |
| **사번 조회** | 한 사람의 채무가 왜 그 금액인지 봅니다 |
| **산출 내역** | 끝낸 산출을 저장하고 다음 결산에 끌어옵니다 |
| **자료실** | 여러 회차에 걸쳐 쓰는 자료를 넣어 둡니다 |

맨 위 **단체** 칸은 회사별 서랍입니다. 산출 내역과 전기 연결이 단체별로 갈라져
있어, 여러 회사를 맡아도 섞이지 않습니다.

## 산출

### 1. 명부 파일

받은 명부 통합문서를 그대로 올립니다. `.xlsx` `.xlsm` `.xls` 다 읽습니다.

자주 쓰는 명부는 **[이 파일을 목록에 저장]** 으로 넣어 두면 다음부터 고르기만
하면 됩니다.

### 2. 기초율 (산출가정)

두 가지 중 하나입니다.

- **[산출가정 입력] 탭에서 만든 것 쓰기** — 화면에서 채운 가정을 그대로 씁니다
- **파일 업로드** — 기초율 워크북을 올립니다

기초율 파일이 처음이면 [산출가정 입력] 탭에서 만드는 쪽이 빠릅니다.

### 3. 산출 기준일

비우면 명부의 `기본정보` 시트에 적힌 날짜를 씁니다. 여기 넣으면 **명부를 고치지
않고** 기준일만 바꿔 볼 수 있습니다. 가결산이나 기준일 확정 전 시산에 씁니다.

산출 시작일은 직전 결산일 다음 날입니다. 이자원가를 이 기간으로 환산하므로,
결산기가 바뀌어 1년이 아닌 회차에서 특히 중요합니다.

### 4. 산출 옵션

| 옵션 | 무엇 |
|---|---|
| 검증 오류가 있어도 강행 | 오류를 알면서 끝까지 돌려 봅니다. **검토용입니다** |
| 민감도분석 포함 | 할인율·임금상승률 등을 흔든 결과. 주석 공시에 씁니다 |
| 기타장기종업원급여 별도 산출 | 근속포상·장기근속휴가가 있는 회사만 |
| 재측정요소 가정별 분해 | 가정변경효과를 사망률·퇴직률·임금·할인율로 쪼갭니다 |

마지막 것은 가정을 하나씩 갈아 끼우며 재는 것이라 **명부 전체 산출이 네 번 더**
돕니다. 전기 기초율을 연결한 회차에서만 값이 나옵니다.

### 5. 전기 산출 결과

전기말 채무와 할인율을 넣으면 증감분석(기초 → 기말)이 만들어집니다. 지난 회차를
이 앱에서 저장해 두었다면 **[입력 불러오기]** 로 한 번에 채워집니다.

### 6. 사외적립자산

신탁회사 명세서의 숫자를 그대로 옮깁니다. 명부의 `사외적립자산` 시트에 이미
채워져 있으면 자동으로 읽어 오므로, 비어 있는 칸만 손보면 됩니다.

**미지급 퇴직급여** 와 **자산인식상한(문단 64)** 도 그 시트의 '그 밖의 입력' 에
적혀 있으면 함께 들어옵니다. 상한은 **비운 것과 0 이 다릅니다** — 비우면
미적용이고, 0 을 적으면 초과적립액을 전부 깎습니다.

### 실행하고 나면

- **검증 결과** 를 먼저 봅니다. 오류가 있으면 그 위의 숫자는 믿을 수 없습니다
- 결과 엑셀·개인별 결과를 내려받습니다
- 이름을 붙여 **저장** 하면 [산출 내역] 에 쌓입니다. `2412` 처럼 결산기만 적어도
  됩니다 — 단체가 이미 갈라져 있습니다

> 아이패드에서 내려받은 파일은 **파일 앱 → 다운로드** 에 들어갑니다.

## 산출가정 입력

기초율 워크북을 엑셀로 만들지 않고 화면에서 채웁니다. 다 채우면 그대로 산출에
쓸 수 있고, 파일로 내려받을 수도 있습니다.

### 시스템 등록 자료

[자료실] 에 넣어 둔 **금리표·표준률** 을 불러와 할인율·퇴직률·승급률·사망률 표를
한 번에 채웁니다. 손으로 옮기면 자릿수를 틀리기 쉬운 자리라 이렇게 했습니다.

불러온 뒤 값을 고쳐도 됩니다. 등록된 것은 출발점이지 확정이 아닙니다.

### 직군별 규정

직군을 어떻게 나눌지와, 직군마다 어떤 지급률·퇴직률·승급률 규정을 걸지
정합니다.

명부의 직군 표기가 회사마다 다르므로 **[제안대로 채우기]** 가 있습니다.
`촉탁`·`기간제` 같은 말이 들어가면 계약직, `이사`·`대표` 면 임원으로 찍어 줄
뿐이니 반드시 확인하십시오. 같은 표기라도 정년 후 재고용이면 계약직, 임원 예우
재고용이면 임원인데 그것은 사람만 압니다.

### 지급률

세 가지 방식이 있습니다.

| 방식 | 표에 적는 값 |
|---|---|
| **누적** | 그 근속연수까지의 **누적 배수** (10년 → 10.0) |
| **누진** | 그 구간에서만 적용할 **연 배수** (0년 1.0 / 5년 1.5 / 10년 2.0 이면 근속 12년 = 5×1.0 + 5×1.5 + 2×2.0 = 16.5) |
| **수식** | 아래 칸에 식을 직접 씁니다 |

법정 퇴직금(근속 1년에 30일분)이면 누적 방식에 근속연수를 그대로 적으면 됩니다.

**사유별 차등** 을 켜면 그 직군이 중도·사망·정년 세 열로 갈립니다. 사유마다
배수가 다른 규정에 씁니다. 비운 열은 왼쪽의 기본 규정을 그대로 씁니다.

배수가 아닌 것 — 정액 가산, 근속 하한, 가산 귀속 — 은 세 열로 담기지 않으므로
아래 **[퇴직사유별 차등]** 표에 한 줄씩 적습니다.

### 장기급여

근속포상·장기근속휴가가 있는 회사만 씁니다. 지급유형이 넷입니다.

- **정액** — 근속 몇 년에 얼마
- **휴가** — 며칠. 1일 통상임금으로 환산합니다
- **현물** — 물품. 평가시점 시세로 환산한 금액을 넣고 근거를 적어 둡니다
- **급여비례** — 평균임금의 몇 %

재직 중에 주는 것과 퇴직할 때만 주는 것은 채무 잡히는 방식이 다르므로 구분해
적습니다.

## 분석

산출이 끝나면 자동으로 채워집니다. 접었다 펴는 묶음으로 되어 있습니다.

- **개인별 채무 해부** — 한 사람을 골라 연차별 근거를 봅니다
- **직군별 집계** · **증감분석 · 사외적립자산** · **차년도 예측**
- **민감도 분석** — 가정을 흔들었을 때 채무가 얼마나 움직이는지
- **경과기간별 예상 지급액** — 앞으로 언제 얼마가 나가는지
- **적용한 기초율** — 이 산출이 실제로 쓴 값 전부

## 계리평가 보고서

**퇴직급여 보고서** 와 **장기급여 보고서** 두 가지를 만듭니다. K-IFRS 1019호
문단 135~147 의 공시 요구 항목을 담았습니다.

미리보기에서 **[인쇄 / PDF 저장]** 을 누르고

- 아이패드 — 인쇄 화면의 **공유 → 파일에 저장**
- PC — 프린터 대신 **PDF로 저장**

보고서 숫자는 산출 결과를 그대로 옮긴 것이라 화면 요약·결과 엑셀과 원 단위까지
같습니다.

---

## 사번 조회

전체 산출은 몇백 명의 합계라 "이 사람 채무가 왜 이 금액인가" 에 답하지
못합니다. 사번 하나를 같은 명부·기초율로 **다시 산출** 해 연차별 근거를 한 줄씩
보여 줍니다.

인적사항, 적용한 규정, 연차마다의 연령·근속·임금·퇴직확률·지급액·귀속액·
할인계수·채무 기여가 나오고, **근거 줄의 합이 곧 그 사람의 확정급여채무** 입니다.
전체 산출의 그 사람 몫과 원 단위까지 같습니다.

담당자나 감사인이 한 사람을 짚어 물었을 때 이 화면을 그대로 보여 주면 됩니다.

## 산출 내역

이름을 붙여 저장한 산출이 쌓입니다. 명부·산출가정·결과가 통째로 남습니다.

- **[불러오기]** — 그 회차의 결과를 다시 화면에 올립니다. 분석·보고서·사번 조회가
  그 회차 기준으로 바뀝니다
- **[입력 불러오기]** — 다음 결산에서 전기 입력과 전기 채무를 그대로 끌어옵니다
- **[내려받기]** — 결과 엑셀을 다시 받습니다

같은 이름으로 저장하면 덮어씁니다.

## 자료실

여러 회차·여러 단체에 걸쳐 쓰는 자료를 넣어 둡니다.

| 종류 | 무엇 |
|---|---|
| **가정세트** | 지급률·지급규정까지 포함한 산출가정 한 벌 |
| **금리표** | 등급별 기간구조. 할인율 탭을 한 번에 채웁니다 |
| **명부** | 올렸던 명부 보관 |
| **표준률** | 퇴직률·승급률·사망률 워크북 |

**시험 명부 만들기** 는 난수로 가상 명부를 만듭니다. 실제 명부 없이 프로그램을
두드려 볼 때 씁니다. 성격이 다른 세 가지가 있고, 자료가 험한 것도 있습니다.

### 보관함 — 기기 밖에 저장

**[보관함 내보내기]** 를 누르면 등록 자료와 산출 내역 전부가 zip 하나로
내려옵니다. 아이패드에서 **공유 → 파일에 저장 → iCloud Drive** 로 두면 기기를
바꿔도 남습니다.

되돌릴 때는 두 가지입니다.

- **가져오기 (합치기)** — 지금 자료를 두고 같은 이름만 덮어씁니다
- **전체 교체** — 지금 것을 비우고 보관함 그대로 되돌립니다

## 막힐 때

**고쳤는데 옛 화면이 뜬다**
새로고침하십시오. 그래도 그러면 홈 화면 아이콘을 지웠다 다시 추가합니다.

**산출이 안 된다**
검증 결과를 먼저 봅니다. 오류가 있으면 그 사람은 산출에서 빠지고, 오류가 많으면
아예 멈춥니다. 급하면 [검증 오류가 있어도 강행] 을 켜서 어디까지 도는지 보되,
그 결과를 그대로 쓰지는 마십시오.

**"산출기준일을 찾지 못했습니다"**
명부에 기준일이 없는 경우입니다. [3. 산출 기준일] 에 직접 넣으면 됩니다.

**저장 공간이 부족하다고 한다**
[자료실] 에서 안 쓰는 명부·산출 내역을 지웁니다. 내보내기를 먼저 해 두고
지우십시오.
