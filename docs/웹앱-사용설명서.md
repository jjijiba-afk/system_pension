# 사용설명서

K-IFRS 제1019호(종업원급여) 확정급여채무를 산출합니다. 예측단위적립방식(PUC)으로
채무·근무원가·이자원가를 내고, 공시에 필요한 항목을 표로 만들어 줍니다.

브라우저만 있으면 됩니다. 설치할 것도, 로그인할 것도 없습니다.

# 1. 시작하기

## 1.1 여는 법

### 주소를 열면 됩니다

받으신 주소를 주소창에 치면 그대로 열립니다.
크롬·엣지·사파리·삼성인터넷 모두 됩니다. 갤럭시·아이폰·아이패드·PC 어디서나
같은 화면입니다.

## 1.2 앱처럼 두고 쓰기 (권장)

| 기기 | 방법 |
|---|---|
| 갤럭시 (삼성인터넷·크롬) | 메뉴 → `홈 화면에 추가` |
| 아이폰·아이패드 (사파리) | 공유 → `홈 화면에 추가` |
| PC (크롬·엣지) | 주소창 오른쪽 설치 아이콘 → `설치` |

붙여 두면 주소창 없는 창으로 열리고, **한 번 연 뒤에는 인터넷이 끊겨도 돕니다.**
계산이 전부 기기 안에서 돌기 때문입니다.

## 1.3 첫 화면

처음 열면 [자료실]에 무엇이 들어 있는지 알려 주는 안내창이 뜹니다.
**[다시 보지 않기]** 를 누르면 다음부터 안 뜹니다. 같은 내용은 화면 오른쪽 위
**물음표** 안에 그대로 있습니다.

## 1.4 자료가 어디로 가는가

**아무 데도 가지 않습니다.**

명부 파일을 고르면 그 파일은 브라우저 안에서 열리고, 계산도 브라우저 안에서
끝납니다. 서버로 올라가는 것이 없습니다. 화면을 닫아도 기기 안에는 남아 있어
다음에 열면 이어서 볼 수 있고, 지우고 싶으면 [산출 내역]이나 [자료실]에서
지우면 됩니다.

개인정보 검토를 받을 때 이 문장을 그대로 쓰셔도 됩니다 —
**명부는 회사 기기 밖으로 나가지 않습니다.**

| 시트 | 무엇 |

## 2.2 열은 이름으로 찾습니다

프로그램은 열 번호(A열·B열…)를 세지 않고 **3행의 머리글 글자**를 봅니다.
그래서

* **순서를 바꿔도 됩니다**
* **인사팀이 쓰던 이름 그대로 보내도 읽힙니다** — `사번`을 `사원번호`·`사원코드`
  로, `30일 평균임금`을 `월평균임금`·`평균임금`으로 적어도 같은 칸으로 봅니다
* **회사 열을 오른쪽에 더 붙여 보내도** 그대로 읽습니다

명부를 우리 양식에 맞춰 옮겨 적을 필요가 없다는 뜻입니다. 인사팀에는
"쓰시던 양식 그대로 주세요" 라고 하시면 됩니다.

머리글 행을 못 찾으면 화면이 알려 줍니다(`LAYOUT_HEADER_NOT_FOUND`).

## 2.3 색이 뜻하는 것

열이 다섯 묶음으로 갈려 있고 머리글 색이 다릅니다.

| 색 | 묶음 | 뜻 |
|---|---|---|
| 남색 | **필수** | 비면 그 사람은 산출되지 않습니다 |
| 청록 | 제도·근속 | 해당자만. 비우면 아래 '비우면' 대로 봅니다 |
| 자주 | 장기급여 | 근속포상·장기근속휴가가 있는 회사만 |
| 갈색 | 개인 예외 | 이 사람만 직군 규칙과 달라야 할 때 |
| 회색 | 기타 | 드물게 쓰는 항목과 관리용 |

**해당 없는 묶음은 통째로 지우고 보내도 됩니다.**

# 3. 산출가정

두 가지 방법이 있습니다. 섞어 써도 됩니다.

## 3.1 방법 A — 화면에서 입력 (권장)

[산출가정 입력] 탭에서 직접 넣습니다.

* **할인율** — 한 줄이면 전 기간 단일 할인율, 여러 줄이면 기간구조로 봅니다.
  [자료실]의 금리표에서 등급·기준일을 골라 불러올 수 있습니다.
* **임금상승률** — Base-up 과 승급률을 나눠 넣습니다. Base-up 기본값은 2%.
* **퇴직률 · 승급률 · 사망률** — [표준률 불러오기]를 누르면 표준률이 들어옵니다.
  회사 경험률이 있으면 덮어쓰면 됩니다.
* **지급률 규정** — 아래 3.3 참고.

## 3.2 방법 B — 엑셀로 입력

[자료실] → `기초율_빈양식.xlsx` 를 받아 채웁니다. 표준률은 화면에서
[표준률 불러오기] 를 눌러 넣는 편이 빠릅니다.

**기초율 파일의 `지급규정` 시트가 명부 `기본정보`의 직군 규칙보다 우선합니다.**

## 3.3 지급률 규정 — 세 가지 방식

| 방식 | 언제 | 어떻게 적나 |
|---|---|---|
| **누적** | 법정 퇴직금처럼 근속에 비례 | 근속연수별 누적 배수 표 |
| **누진** | 근속 구간마다 배수가 다를 때 | 구간별 연 배수 표 |
| **수식** | 상한·하한·조건이 붙을 때 | 엑셀형 수식 한 줄 |

수식 방식에서 쓸 수 있는 변수: `t`(근속연수) · `x`(연령) · `N`(정년) ·
`S`(30일 평균임금) · `직군` · `제도` · `임직원` · `배수`.

예) `MIN(t, 20) * 1.5 + MAX(t - 20, 0) * 2.0`

> 식에서 `배수`를 직접 쓰면 명부의 `임원지급배수`를 밖에서 다시 곱하지 않습니다
> (두 번 곱하는 것을 막기 위해서입니다).

퇴직사유별로 지급률을 다르게 걸 수도 있습니다 — 정년 / 중도 / 사망.
사망 시 정액 가산금 같은 것도 여기서 넣습니다.

## 3.4 직군 매핑

명부의 직군 표기가 회사 인사규정대로 오면(`정규사원`·`촉탁사원`·`임원(별정)`…)
화면에서 묶어 줍니다. **여기서 임원으로 묶은 직군이 임원 취급을 받습니다.**

같은 `촉탁사원`이라도 정년 후 재고용이면 계약직, 임원 예우 재고용이면 임원인
회사가 있습니다. 그래서 기계가 정하지 않고 **사람이 확정합니다.**

난수로 만든 가상 명부이며 실존 인물이 아닙니다.

### 특이사항 한 가지씩 — 한 벌

위의 세 벌은 특이사항 열두 가지를 **한 사람씩** 심어 한 파일에 몰아 넣은
것입니다. 무엇이 있는지 훑기에는 좋지만, "이 숫자가 왜 이렇게 나왔나" 를
따지기에는 쓸 수 없습니다 — 한 사람만 달라진 것이라 채무 전체에서 티가 나지
않기 때문입니다.

이쪽은 반대입니다. **사람은 한 벌**이고 **명부 하나에 특이사항 하나**를
전원 또는 한 직군 전체에 겁니다. 특이사항이 없는 기준 명부도 함께 나오므로,
두 명부의 채무 차이가 곧 그 특이사항이 만든 차이입니다.

[확정급여채무까지 재기] 를 켜면 전부 산출해 **기대한 방향대로 움직였는지**
까지 안내문에 적어 줍니다.

# 5. 검증 읽는 법

산출 전에 명부를 훑어 이상한 곳을 알려 줍니다.

| 등급 | 뜻 |
|---|---|
| **오류 (ERROR)** | 그 사람은 산출되지 않습니다. 명부를 고쳐야 합니다 |
| **경고 (WARNING)** | 산출은 되지만 확인이 필요합니다 |

메시지에 **시트 · 열 · 행 · 사번** 이 같이 나옵니다.
`재직자명부!K28` 이면 그 시트의 K열 28행입니다.

## 자주 보는 것

| 코드 | 무슨 뜻 |
|---|---|
| `JAE_DUP_ID` | 사번 중복. 인사시스템에서 두 번 뽑아 붙인 명부에서 흔합니다 |
| `JAE_JOB_GROUP_UNKNOWN` | 규정에 없는 직군. [직군 매핑]에서 묶어 주세요 |
| `JAE_WAGE_BELOW_CHECK` | 평균임금이 하한 미만. **임금 단위(천원/원) 혼재를 여기서 잡습니다** |
| `JAE_HIRE_AFTER_BASE` | 입사일이 산출기준일보다 늦음 (내년 입사 예정자가 섞여 옴) |
| `JAE_BIRTH_AFTER_HIRE` | 생년월일과 입사일이 뒤바뀜 |
| `JAE_PLAN_MISSING` | 제도구분 누락 |
| `JAE_LEAVE_DAYS_RANGE` | 휴직차감일수가 상식 밖. **연수를 적으신 것 아닌지** |
| `JAE_DB_RATIO_RANGE` | DB비율이 0~1 밖 |
| `JAE_RESIDENT_TOO_LONG` | 주민번호 뒷자리까지 들어옴. 받은 파일에서 지우세요 |
| `JAE_NRA_NOT_FUTURE` | 확정된 정년이 현재 연령 이하. 정년초과 가산연령을 확인하세요 |
| `JAE_PAYOUT_MULTIPLE_APPLIED` | 지급배수가 규정 위에 곱해진다는 **안내**. 맞게 쓰고 있다는 뜻입니다 |

**경고가 하나도 없어야 하는 것은 아닙니다.** 맨 아래 것처럼 "이렇게 계산했다"
는 안내도 경고로 나옵니다.

# 6. 결과 보기

## 6.1 먼저 볼 두 가지

**`산출요약`** — 확정급여채무 · 당기근무원가 · 이자원가 · 잔존만기(듀레이션)

**`추계액대비`** — DBO ÷ 회사 추계액. 통상 **0.7 ~ 1.1** 입니다.
크게 벗어나면 지급률 규정이나 정년 설정을 다시 보세요.

## 6.2 사번 조회

숫자가 미심쩍을 때 **여기부터** 봅니다. 한 사람의 산출 과정이 연도별로 펼쳐집니다.

* 적용한 지급률 규정 · 퇴직률 규정 · 정년 · 투영연수
* 연차별 생존확률 · 지급률 · 예상 급여 · 귀속액 · 현가
* 퇴직사유별(정년·중도·사망) 몫

한 사람 것이 맞으면 대개 전체도 맞습니다.

## 6.3 분석 탭

| 표 | 무엇 |
|---|---|
| 개인별 채무 해부 | 사람마다 무엇이 채무를 만들었는지 |
| 직군별 · 급부별 집계 | 직군별, 그리고 정년·중도·사망 사유별 |
| 증감분석 · 사외적립자산 | 기초 → 기말 변동을 항목별로 (문단 141) |
| 차년도 예측 | 다음 결산의 채무·자산 |
| 민감도 분석 | 할인율·임금상승률 ±0.5%p 등 (문단 145) |
| 경과기간별 예상 지급액 | 만기분석 (문단 147(c)) |
| 적용한 기초율 | 실제로 무엇이 쓰였는지 |

## 6.4 계리평가 보고서

공시에 넣는 항목이 순서대로 나옵니다. **인쇄 → PDF로 저장**하면 됩니다.

## 6.5 엑셀로 받기

**[결과 내려받기]**. 산출요약 · 개인별 · 직군별 · 정리된 명부가 시트로 들어갑니다.
`재직자명부`·`퇴직자명부` 시트는 **프로그램이 읽은 형태로 정리한 명부**라,
원자료를 되짚을 때 씁니다.

# 7. 저장과 비교

## 7.1 산출 내역

돌린 결과에 이름을 붙여 저장합니다(`2512 결산` 처럼). 나중에 불러오면 요약과
엑셀을 다시 볼 수 있습니다. 같은 이름으로 저장하면 덮어씁니다.

**기기 안에 저장됩니다.** 다른 기기에서는 안 보입니다. 옮기려면 [자료실]의
**보관함 — 기기 밖에 저장** 으로 파일을 내보내고 그쪽에서 불러오세요.

## 7.2 전기 대비 검증

전기 산출을 저장해 두었으면, 당기 명부를 전기와 맞대어 봅니다. 당기 명부만
봐서는 알 수 없는 것이 잡힙니다 — 생년월일이 바뀐 사람, 근속이 거꾸로 간 사람,
임금이 급변한 사람, 사라진 사람.

# 8. 안 될 때

| 증상 | 볼 것 |
|---|---|
| 파일을 골랐는데 아무 일도 없음 | `.xlsx`/`.xls` 가 맞는지. 다른 프로그램에서 열려 있으면 닫고 다시 |
| "머리글 행을 찾지 못했습니다" | 명부 3행에 머리글이 있는지. 위에 안내문 줄이 더 있어도 찾습니다만, 아예 없으면 못 찾습니다 |
| 사람 수가 모자람 | 입사일이 기준일보다 늦은 사람은 빠집니다. **DC 가입자도 확정급여채무에서 빠집니다** |
| 채무가 이상하게 큼/작음 | `추계액대비` 먼저. 임금 단위(천원/원) 혼재가 가장 흔합니다 |
| 임원 채무가 이상함 | [직군 매핑]에서 임원으로 묶였는지. `임원지급배수`가 두 번 곱해지지 않았는지 |
| 계약직 채무가 너무 큼 | `잔여계약기간`을 적었는지. 안 적으면 정년까지 근무하는 것으로 봅니다 |
| 화면이 예전 것으로 보임 | 새로고침. 앱으로 설치했으면 닫았다 다시 열기 |
| 산출이 오래 걸림 | 300명 기준 몇 초입니다. 민감도·장기급여를 켜면 몇 배가 됩니다 |

# 9. 기억할 것

1. **명부는 기기 밖으로 나가지 않습니다.**
2. **열은 머리글 글자로 찾습니다** — 인사팀 양식 그대로 받으세요.
3. **`추계액` 칸을 꼭 받으세요.** 이게 없으면 우리 값이 맞는지 대볼 기준이
   없습니다. 지급률을 잘못 걸어도 알아챌 방법이 없어집니다.
4. **숫자가 미심쩍으면 [사번 조회]부터.** 한 사람이 맞으면 대개 전체도 맞습니다.
5. **DC 가입자는 채무에서 빠집니다.** 인원이 안 맞으면 이것부터 확인하세요.
