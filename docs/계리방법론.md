# 계리 방법론

K-IFRS 1019호 '종업원급여' 에 따른 확정급여채무 산출 방법과, 이 시스템이 내린
판단들을 정리합니다.

## 1. 예측단위적립방식 (PUC)

기준서 문단 67은 확정급여채무를 **예측단위적립방식** 으로 측정하도록 합니다.
급여를 근무기간에 걸쳐 배분하고, 각 기간에 배분된 몫을 별개의 급여 단위로 보아
할인합니다.

재직자 한 명에 대해 산출기준일부터 정년까지 1년 단위로 투영합니다.

```
DBO = Σ_t  급여(t) × (과거근속 / 총근속(t)) × 탈퇴확률(t) × v(t)
SC  = Σ_t  급여(t) × (1 / 총근속(t))        × 탈퇴확률(t) × v(t)
```

### 각 항의 정의

**임금 투영** — 해당 연도 초에 인상된다고 봅니다.

```
임금(t) = 30일 평균임금 × Π_{k=1..t} (1 + Base-up(k) + 승급률(연령_k, 근속_k))
```

Base-up과 승급률을 나눠 받는 이유는 성격이 다르기 때문입니다. Base-up은 전원에게
같이 걸리는 기본 인상이고, 승급률은 연령·근속에 따라 사람마다 다릅니다. 한 칸으로
합쳐 받으면 젊은 직원의 승급을 정년 직전 직원에게도 물리게 됩니다.

**탈퇴확률** — 중도퇴직과 사망을 함께 적용합니다. 두 률은 **다중탈퇴율
(종속률)** 로 봅니다 — 여러 원인이 함께 있는 집단에서 그 원인으로 나가는
확률이라는 뜻이라, 그대로 더해 쓰고 겹침 보정을 하지 않습니다.

```
연도 t 중 탈퇴 = 재직확률(t-1) × (w_t + q_t)  — 중도 몫 w_t, 사망 몫 q_t
재직확률(t)   = 재직확률(t-1) × (1 − w_t − q_t)
```

탈퇴는 연중앙(`t − 0.5`)에 일어난 것으로 보고, 정년까지 남은 사람은 마지막
시점(`t = n`)에 전원 퇴직합니다. 따라서 탈퇴확률의 합은 항상 1이며,
`tests/test_valuation.py::test_exit_probabilities_sum_to_one` 이 이를 검증합니다.

**급여** — 지급률 표에서 총근속에 대한 배수를 찾아 투영임금에 곱합니다.

```
급여(t) = 지급률(총근속(t)) × 임금(t)
```

지급률 표는 **정수 근속 사이를 선형보간** 해 읽습니다. 배수는 근속과 함께
이어 쌓이는 양이라 계단으로 읽으면 12.4년이 12년과 같은 급여가 되기
때문입니다. '연단위 절사 지급' 같은 만근속 규정은 표를 계단으로 만드는 것이
아니라 명부의 **차감근속연수** 로 설계합니다. (승급률·퇴직률·사망률 표는
그대로 계단식입니다 — 그 표들은 그 나이의 연간 확률이지 쌓이는 양이 아닙니다.)

지급률 규정을 찾지 못하면 **법정 퇴직금** 으로 봅니다. 근로자퇴직급여보장법의
계속근로 1년당 30일분 평균임금이며, 급여 기준이 이미 30일 평균임금이므로
지급 배수는 근속연수와 같습니다.

**귀속비율** — 근속이 아니라 **급여식이 내는 배수** 로 잽니다.

```
귀속비율 = 지급배수(과거근속) / 지급배수(총근속)
당기 1년치 = [지급배수(과거근속+1) − 지급배수(과거근속)] / 지급배수(총근속)
```

`과거근속 / 총근속` 을 쓰면 급여가 근속에 비례하지 않는 규정에서 틀립니다.
30년 상한 규정에서 근속 35년인 사람은 더 일해도 급여가 늘지 않으므로 이미
전액이 귀속돼 있어야 하는데, 근속비로 재면 총근속이 늘수록 오히려 귀속비율이
줄어 채무가 과소계상됩니다. 문단 70은 **추가 근무가 유의적인 급여 증가를 낳지
않는 시점에 귀속을 멈추도록** 합니다.

배수가 근속에 비례하는 법정 퇴직금에서는 두 방식이 정확히 같은 값을 냅니다.
그때는 `DBO = 근무원가 × 과거근속` 도 성립합니다(비례하지 않으면 성립하지
않는 것이 정상입니다).

임금은 분자·분모에 똑같이 곱해지므로 배수만 보면 됩니다. 배수가 0 이하인
가감 규정에서는 근속비로 되돌립니다.

**할당 방식은 [지급규정]에서 고를 수 있습니다** — `급여식`(기본)과
`근속비례`. 근속비례는 `과거근속 ÷ 총근속` 으로 귀속하는 전통적 방식으로,
근속기간할당으로 산출하는 다른 시스템과 원 단위로 맞출 때 씁니다. 배수가
근속에 비례하는 법정 퇴직금에서는 두 방식이 같은 값을 냅니다.

**할인** — 할인율 시트가 한 줄이면 전 기간 단일 할인율, 여러 줄이면 각 연차의
현물이자율로 보고 `v(t) = (1 + s_t)^(-t)` 로 할인합니다.

기준서 문단 83은 결산일 현재 우량회사채의 시장수익률을 쓰되, 만기가
**확정급여채무의 예상 지급시기와 통화·기간이 일치** 해야 한다고 합니다.
그래서 리포트에 가중평균 잔존만기(듀레이션)를 함께 표시합니다. 회사채 만기를
고를 때 근거로 쓰십시오.

### 근속연수

중간정산일(있으면)부터 셉니다. 중간정산으로 그 이전 근속에 대한 채무가 이미
정산되었기 때문입니다. 명부의 휴직차감일수만큼 기산일을 뒤로 밀고, 그 기간을
뺍니다.

단수 처리(절사·반올림 등)는 **미래 시점마다 다시** 겁니다. 오늘 근속을 한 번
깎아 두고 거기에 연수를 더하면, '1년 미만 절사' 인 회사에서 미래 급여가 반년치
가량 부풀어 오릅니다.

### 정년연령을 정하는 순서

한 사람의 퇴직 시점은 아래 차례로 정해집니다. 위에서 걸리면 아래는 보지 않습니다.

1. **잔여계약기간** — 계약 만료로 나가는 사람. `현재연령 + 올림(잔여연수)`
2. **임금피크 연령** — 현재 연령보다 크면 그 연령
3. **개인 정년연령** — 명부에 사람마다 적어 온 값
4. **직군 규칙의 정년** — 임원이면 임원 정년
5. 이미 정년을 넘겼으면 `현재연령 + 정년초과 가산연령`

### 급여를 깎거나 얹는 것들

| 항목 | 어디에 걸리나 |
|---|---|
| **가입자격(최소 근속연수)** | 못 채우고 나가면 급여 0. 대상에서 빼는 것이 아니라 **급여식에서 0** 으로 둡니다 — 지금은 짧아도 정년까지 남으면 받게 되므로 그 몫은 채무에 잡혀야 합니다 |
| **개인 지급배수** | 명부에 적혀 와도 **엔진이 스스로 곱하지 않습니다.** 그 칸에 담긴 것이 회사마다 달라(배수·누적 지급배수·한도) 넘겨짚으면 한 사람이 총액을 흔듭니다. 쓰려면 지급률 규정을 수식 방식으로 두고 식에서 `배수` 를 부릅니다 |
| **추가지급 기본급** | 마찬가지로 **저절로 더해지지 않습니다.** 사망 위로금인 회사와 명퇴 가산금인 회사가 섞여 오는데, 사유를 가리지 않고 얹으면 채무가 배로 뜁니다. 얹으려면 [퇴직사유] 표의 가산액에 적거나 식에서 `추가급` 을 부릅니다 |
| **DB비율** | 규정이 내는 급여(기본+가산)에 곱합니다 |
| **지급액 반올림** | 실제 지급액에 거는 것이므로 **합계에 한 번** 걸고, 그 비율만큼 기본·가산 몫을 함께 조정합니다 |
| **누진 보전** | 연봉제 전환 전 구간의 배수를 얼려 둡니다. 근속은 이어지고 배수만 구간에서 갈립니다 |

## 1-2. 퇴직사유별 지급률

같은 회사도 **정년 / 중도 / 사망** 에 지급률이 다른 경우가 많습니다. 사유마다
따로 산출해 합칩니다.

```
DBO = Σ_사유 Σ_t  귀속급여(사유, t) × 그 사유로 나갈 확률(t) × v(t)
```

사유별 규정을 걸지 않으면 전 사유에 같은 규정이 적용되어, 나누지 않은 것과
같은 값이 나옵니다.

**가산 급여** — 사망 시 정액, 정년 시 기본급 몇 개월분처럼 기본 급여에 얹는
몫입니다. 귀속 방식을 두 가지 중에서 고릅니다.

| 귀속 | 뜻 | 언제 |
|---|---|---|
| **근속비례** | 기본 급여와 같은 비율로 쌓입니다 | 근속에 따라 커지는 가산 |
| **즉시** | 오늘 근속으로 재어 그만큼 전액 귀속합니다 | 근속과 무관한 정액. '10년 미만 3개월분 / 이상 5개월분' 처럼 계단이 있으면 지금 올라선 칸까지 |

즉시 귀속이라도 퇴직 시점에 실제로 받을 금액을 넘기지는 않습니다.

사유별 몫은 결과 화면과 리포트에 따로 나옵니다. 합계만 보면 지급률 한 칸을
잘못 넣어도 총액이 조금 움직일 뿐이라 알아채지 못하기 때문입니다.

## 2. 이 시스템이 내린 판단

기준서가 방법을 특정하지 않아 선택이 필요했던 부분입니다. 회사 규정이나 계리사의
판단이 다르면 해당 모듈을 고쳐야 합니다.

| 항목 | 선택 | 근거 |
|---|---|---|
| 탈퇴 시점 | 연중앙 (`t − 0.5`) | 기중 균등발생 가정. 연초·연말 가정보다 편의가 작습니다 |
| 임금 인상 시점 | 연초 | 첫 해부터 인상을 반영하는 보수적 처리 |
| 다중탈퇴 결합 | `w + q` (잔존 `1 − w − q`) | 퇴직률·사망률을 다중탈퇴율(종속률)로 보고 그대로 더합니다. 독립률처럼 `(1−w)(1−q)` 로 또 보정하면 이중 차감입니다. 합이 1을 넘는 입력은 사망률을 잘라 막습니다 |
| 정년 도달자 | 마지막 시점 전원 퇴직 | 잔존확률이 새지 않도록 |
| DC 가입자 | 확정급여채무 0 | 기준서 문단 51. 부담금 납입으로 의무가 종료됩니다 |
| 혼합형(DB비율) | 규정 급여 × DB비율 | 같은 문단. DC 로 낸 몫은 의무가 끝났으므로 DB 비중만 남깁니다. 정액 위로금은 제도 분할과 무관해 전액 잡습니다 |
| 잔여계약기간 | 퇴직 시점 = 현재연령 + 올림(잔여연수) | 계약 만료는 근무기간의 **상한** 입니다. 정년·임금피크보다 앞서므로 그 둘을 덮습니다 |
| **가산·차감근속연수** | 지급률 근속 = 할당 근속 + 가산 − 차감 | 군경력 인정·연단위 절사는 **급여 배수를 찾는 근속만** 움직입니다. 귀속(할당)은 실제 근속 그대로입니다 — 입사일을 고쳐 넣으면 할당까지 움직여 틀립니다 |
| 이자원가 (단일 평가) | `DBO × 할인율` | 차기 예상액. 증감분석에서는 아래 식을 씁니다 |

### 이자원가 (증감분석)

전기 산출 결과가 있으면 기중 발생분을 반영합니다.

```
이자원가 = 기초DBO × i + 근무원가 × i × 0.5 − (급여지급 + 정산지급) × i × 0.5
```

기중 균등발생 가정에 따라 근무원가와 지급액에 반년치 이자를 붙입니다.

## 3. 증감분석과 보험수리적손익 분해

기준서 문단 141은 기초에서 기말에 이르는 변동을 항목별로 공시하도록 합니다.
보험수리적손익을 **경험조정** 과 **가정변경효과** 로 나누려면 산출이 세 벌 필요합니다.

| 산출 | 명부 | 가정 |
|---|---|---|
| `기초DBO` | 전기말 | 전기 |
| `DBO(전기가정)` | 당기말 | **전기** |
| `기말DBO` | 당기말 | 당기 |

```
예상 기말채무 = 기초DBO + 근무원가 + 이자원가 + 과거근무원가 − 급여지급 − 정산지급
경험조정     = DBO(전기가정) − 예상 기말채무
가정변경효과 = 기말DBO − DBO(전기가정)
```

가정을 그대로 둔 채 실제 명부로 다시 산출한 값과 예상값의 차이가 **경험조정**
(퇴직·사망·임금인상이 가정과 달랐던 부분)이고, 명부를 고정한 채 가정만 바꿔
생긴 차이가 **가정변경효과** 입니다.

GUI의 `3. 전기 산출 결과` 에 **전기 기초율 파일** 을 넣으면 이 분해가 됩니다.
넣지 않으면 전액을 경험조정으로 잡습니다.

**최초 평가(전기 산출 없음)의 보험수리적손익은 0 입니다.** 손익은 가정과
실제의 차이인데 비교할 전기 채무 자체가 없기 때문입니다. 이때 기말채무에서
당기근무원가를 뺀 잔액은 증감표에 `최초 인식` 줄로 따로 표시됩니다.

## 3-2. 사외적립자산과 순확정급여부채

```
순확정급여부채 = 확정급여채무 − 사외적립자산 공정가치
```

자산이 채무를 넘으면 그 초과분을 그대로 자산으로 잡지 않습니다. 문단 64는
**환급받거나 미래 기여금을 줄여 실제로 얻을 수 있는 경제적 효익** 만 인정하도록
합니다(자산인식상한). 상한을 넘는 몫은 재측정요소로 처리합니다.

자산의 기대수익은 **채무에 쓴 할인율과 같은 율** 로 계산합니다(문단 125).
실제 수익과의 차이는 재측정요소입니다.

## 3-3. 할인율 관련 공시

**단일 가중평균 할인율 (문단 85)** — 기간구조로 할인했으면 곡선으로 낸 채무와
**같은 현가를 내는 하나의 이자율** 을 역산해 표시합니다. 시점별 현금흐름이
있어야 풀 수 있으므로, 산출 과정에서 지급 시점별 금액을 함께 들고 있습니다.

**만기분석 (문단 147(c))** — 앞으로 경과기간별로 얼마가 나갈지 표로 냅니다.
이때는 **귀속 전, 할인 전** 금액입니다. 채무는 지금까지 쌓인 몫만 담지만,
만기분석은 그때 실제로 나갈 돈 전체를 보이는 것이기 때문입니다.

## 4. 민감도분석

기준서 문단 145는 유의적인 각 보험수리적 가정의 합리적으로 가능한 변동이
채무에 미치는 영향을, **다른 가정은 불변** 으로 두고 공시하도록 합니다.

기본 제공 항목:

| 가정 | 변동폭 |
|---|---|
| 할인율 | ±0.5%p |
| 임금상승률 | ±0.5%p |
| 사망률 | ±10% (배수) |
| 퇴직률 | ±10% (배수) |

변동폭을 바꾸려면 `sensitivity.Shock` 목록을 넘기십시오.

### 결과 읽기

할인율과 채무는 반대로 움직입니다. 변동률은 대략 `듀레이션 × 변동폭` 이므로,
듀레이션 9년이면 할인율 +0.5%p에 약 −4.5%가 나옵니다. 크게 벗어나면 기초율이나
명부를 의심해 보십시오.

**퇴직률의 부호는 가정에 따라 뒤집힙니다.** 법정 지급률에서 귀속된 급여액은
`과거근속 × 임금` 으로 탈퇴 시점과 무관하므로, 임금상승률이 할인율보다 낮으면
일찍 나가는 쪽이 덜 할인되어 채무가 **커집니다**. 반대로 임금상승률이 할인율보다
높으면 채무가 줄어듭니다. 부호만 보고 오류로 판단하지 마십시오.
(`tests/test_valuation.py::TestDecrements` 가 양쪽을 모두 검증합니다.)

## 5. 기타장기종업원급여

근속 포상·장기근속휴가처럼 **재직 중 특정 근속연수에 도달하면** 지급되는 급여입니다.
퇴직급여와 구조가 다릅니다.

* 급여 시점은 탈퇴 시점이 아니라 **근속 도달 시점** 입니다. 지급률 표의 각 행
  (근속 10년 → 10일, 20년 → 20일 …)이 하나의 지급 시점이 됩니다.
* 그때까지 **재직해 있어야** 받으므로 재직확률만 곱합니다. 그래서 탈퇴는 언제나
  채무를 줄입니다(퇴직급여와 반대).
* 급여는 `지급일수 × 일 기본급(투영)` 입니다. 일 기본급이 비면 `평균임금 / 30`.
* 귀속비율은 `과거근속 / 도달근속`. 이미 지나간 지급 시점은 채무가 아닙니다.
* 정년 전에 도달하지 못하는 시점은 제외합니다.

기준서 문단 155는 기타장기종업원급여의 보험수리적손익을 **즉시 당기손익** 으로
인식하도록 하므로(퇴직급여는 기타포괄손익), 퇴직급여와 분리해 산출합니다.

산출 대상은 명부의 `장기급여 산출대상여부` 가 `Y` 인 사람입니다.

## 6. 검증

`tests/test_valuation.py` 는 해석적으로 답을 알 수 있는 단순 가정을 넣어 엔진을
교과서 공식과 대조합니다.

* 탈퇴가 정년 하나뿐이면 DBO는 손으로 계산한 값과 일치해야 합니다
* `DBO = 근무원가 × 과거근속`
* 할인율 0이면 `DBO = 과거근속 × 임금` (탈퇴율과 무관)
* 탈퇴확률의 합은 1
* 할인율↑ → 채무↓, 임금상승률↑ → 채무↑

실제 명부로 산출한 뒤에는 리포트의 **`DBO / 퇴직급여추계액` 비율** 을 보십시오.
통상 0.7 ~ 1.1 범위이며, 크게 벗어나면 지급률 규정이나 정년연령 설정을
확인해야 합니다.
