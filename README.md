# 연금계리 산출 시스템

K-IFRS 1019호 '종업원급여' 에 따른 **확정급여채무(DBO) 산출 시스템** 입니다.

명부 정규화·검증 위에 **예측단위적립방식(PUC) 계리 엔진** 을 얹었습니다.
클리닝된 명부와 기초율 엑셀을 넣으면 확정급여채무·근무원가·민감도·증감분석이
담긴 엑셀 리포트가 나옵니다.

---

## 무엇을 하나

| | 이 시스템 |
|---|---|
| 날짜 파싱 | 함수 1개 (`dates.py`), 형식별 회귀 테스트 39건 |
| 오류 처리 | 전부 수집 → **시트·행·열·사번** 과 함께 리포트 |
| 명부 끝 판정 | 실제 마지막 행을 탐색 (중간 빈 칸이 있어도 누락 없음) |
| 메모리 | 명부 크기에 비례 |
| 산출 범위 | DBO·근무원가·이자원가·민감도·증감분석·장기급여 |
| 실행 | 단일 EXE (설치 불필요) · 브라우저 웹앱 |

규칙이 서로 어긋나 **자동으로 고르지 않고 경고만 남긴** 항목은 검증 리포트에
그때그때 표시됩니다.

## 빠르게 써 보기

### 실행파일 (권장 — 파이썬 설치 불필요)

1. GitHub 저장소 → **Actions** 탭 → 최근 `Windows 실행파일 빌드` 실행 →
   **Artifacts** 의 `연금계리산출-windows` 다운로드
2. 압축(`연금계리산출.zip`)을 풀고 `연금계리산출.exe` 더블클릭

압축 안에 **기본자료** 폴더가 함께 들어 있습니다. 회사 자료를 넣기 전에
그 두 파일만으로 한 번 돌려 보면 흐름이 보입니다.

| 파일 | 내용 |
|---|---|
| `기본자료/명부_양식.xlsx` | 빈 명부 양식 (작성 예시 두 줄 포함) |
| `기본자료/기초율_기본값.xlsx` | 사망률·퇴직률·지급률이 채워진 기초율 |
| `기본자료/기초율_빈양식.xlsx` | 처음부터 회사 값으로 채우고 싶을 때 |

사망률은 통계청 「2024년 생명표」 공표치에 맞춘 값이라 그대로 쓸 수 있습니다.
**할인율·퇴직률·승급률은 회사 값으로 바꿔야 합니다** — 특히 퇴직률은 채무에
가장 크게 영향을 주는 가정입니다.

### 소스에서 실행

```bash
pip install -e .

# GUI
python -m pension

# 배치
python -m pension assumptions --roster 명부.xlsm            # 산출 가정 입력 화면
python -m pension template 기초율.xlsx --roster 명부.xlsm   # 기초율 양식 생성
python -m pension samples 기본자료                           # 명부 양식·기초율 기본값 한 벌
python -m pension check 명부.xlsm                            # 검증만
python -m pension calc 명부.xlsm 기초율.xlsx -o 산출결과.xlsx
python -m pension members 명부.xlsm 기초율.xlsx -o 개인별결과.xlsx  # 개인별 결과만
```

## 입력 파일 두 개

### 1. 명부 워크북

명부 통합문서를 그대로 씁니다. 시트 구조와 행 위치가 같아야 합니다.

| 시트 | 내용 | 데이터 시작 행 |
|---|---|---|
| `Input` | 산출기준일(C3), 평균임금 체크금액(C5), 직군 규칙(B12~N36) | 12 |
| `재직자명부` | 사번·직군·생년월일·입사일·평균임금·제도구분 등 36개 칼럼 | 26 |
| `퇴직자명부` | 퇴사일·지급사유·지급금액 등 24개 칼럼 | 22 |

`Input` 시트 G~N 열(기초율 규정명)을 채우면 **직군 단위로 일괄 적용** 되고,
비워 두면 명부의 해당 칼럼 값을 씁니다.

### 2. 기초율 워크북

GUI의 **[산출 가정 입력]** 화면에서 채우거나, `pension template` 로 양식을 만들어
엑셀에서 채웁니다.

| 시트 | A열 | B열 이후 |
|---|---|---|
| `할인율` | 연차 | 할인율 — 한 줄이면 단일 할인율, 여러 줄이면 현물이자율 기간구조 |
| `임금상승률` | 연차 | Base-up 상승률 (승진·승급 제외) |
| `승급률` | 연령 또는 근속 | 규정명별 승급률 |
| `퇴직률` | 연령 또는 근속 | 규정명별 연간 중도퇴직률 |
| `사망률` | 연령 | 남자 / 여자 |
| `지급률` | 근속연수 | 규정명별 월평균임금 대비 배수 — **비우면 법정 퇴직금** |
| `지급률규정` | 규정명 | 방식(누적/누진/수식) · 수식 |
| `장기급여지급률` | 근속연수 | 규정명별 지급일수 (일 기본급 × 일수) |

지급률은 세 가지 방식으로 적을 수 있습니다 — **누적**(표 값이 누적 배수), **누진**
(표 값이 구간별 연 배수), **수식**(엑셀 문법의 조건부 계산식).
자세한 내용은 [지급률 규정 작성법](docs/지급률규정-작성법.md)을 보십시오.

모든 표는 **계단식 조회** 입니다. 20·25·30세 행만 있으면 27세는 25세 행 값을 씁니다.
A1 셀을 `연령` ↔ `근속` 으로 바꾸면 조회 기준이 바뀝니다.

## 산출 방법

예측단위적립방식으로 재직자 한 명씩 정년까지 1년 단위로 투영합니다.

```
DBO = Σ_t  급여(t) × (과거근속 / 총근속(t)) × 탈퇴확률(t) × 현가계수(t)
```

* 임금은 Base-up + 승급률로 복리 투영
* 탈퇴는 중도퇴직률과 사망률을 함께 적용(`1 − (1−w)(1−q)`), 연중앙 발생 가정
* 정년 도달자는 마지막 시점에 전원 퇴직
* 당기근무원가는 귀속비율만 `1 / 총근속` 으로 바꾼 값

자세한 식과 근거는 [`docs/계리방법론.md`](docs/계리방법론.md) 에 있습니다.

**DC 가입자는 확정급여채무가 없습니다.** 부담금 납입으로 의무가 끝나기 때문이며,
결과의 `제외사유` 칼럼에 이유를 남깁니다.

## 면책

이 시스템은 산출 도구입니다. 기초율(할인율·퇴직률·사망률·승급률)의 적정성과
명부의 정확성은 사용자 책임이며, 재무제표 공시 전에는 계리사의 검토를 받으십시오.
`검증리포트` 시트에 남은 경고는 자동으로 판단할 수 없어 담당자 확인이 필요한
항목입니다.
